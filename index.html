Adding it to email

  1. Outlook: File › Options › Mail › Signatures › New, then paste (Ctrl+V) after “Copy image”, or use the picture button to insert the downloaded PNG. Set its width to about 600 px.
  2. Gmail: Settings › See all settings › Signature › Create new, then click the image icon and upload the PNG.
  3. Leave a field empty to hide that line (phone, email, address, or any social platform).
  4. “Clear fields” only empties the personal details (name, title, phone, email). The company details stay.
