Social media icons (optional)

By default each platform shows a red letter badge (IG, X, FB). To use the official icons instead, save each platform’s icon from its official brand resources as a PNG or SVG, then load it below. The icons are remembered on this computer, so you only need to do this once per PC.

Adding it to email

  1. Outlook: File › Options › Mail › Signatures › New, then paste (Ctrl+V) after “Copy image”, or use the picture button to insert the downloaded PNG. Set its width to about 600 px.
  2. Gmail: Settings › See all settings › Signature › Create new, then click the image icon and upload the PNG.
  3. Leave a field empty to hide that line (phone, email, address, or any social platform).
  4. A second phone or email is shown on the same line as the first, separated by a divider.
  5. “Clear fields” only empties the personal details (name, title, phones, emails). The company details stay.
